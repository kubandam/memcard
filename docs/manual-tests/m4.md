# M4 manual test checklist — memory-card sync

Use a game from your online library that saves to the memory card (e.g. Crash Bandicoot 2/3, Spider-Man).

- [ ] PC 1: play, save in the game's own menu. Within ~30 s (or when you press ← Library) the overlay shows "Saved to cloud · hh:mm".
- [ ] PC 2 (or phone): open the library with your passphrase, start the same game → overlay says "Loaded your save from the cloud" and the in-game Load menu shows the save from PC 1.
- [ ] Save on PC 2, go back to PC 1, start the game → PC 2's save is there.
- [ ] Offline test: disconnect Wi-Fi on PC 1, start the game (it is still downloaded? if not, skip), save → overlay "Saves stay on this PC until you are online". Reconnect, start again → next save syncs.
- [ ] Conflict: save on PC 1 offline, save on PC 2 online, bring PC 1 online and start → cloud save loaded, a file "<game> (this PC, date).srm" is downloaded, notice explains it.
- [ ] Delete the game from the online library → start it again after re-uploading: no old save appears.
