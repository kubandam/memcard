# M1 manual test checklist — Player + bring your own file

Run on the deployed site (or `pnpm dev`) with the fixture from `pnpm fixture` or any homebrew you own.
Tick each line; note the browser/OS where something fails.

## Desktop (Apple-silicon Mac)

- [ ] Chrome: drop a `.chd` on the home page → tile appears with size and "Played never".
- [ ] Reload the page → tile still there. Quit and reopen the browser → still there.
- [ ] Click the tile → Boot screen (glass blocks, title, progress) → game runs within ~10 s.
- [ ] Sound plays (Safari: after the first click on the page).
- [ ] Keyboard: arrows = D-pad, `x` = Cross, `z` = Circle, `s` = Square, `a` = Triangle, Enter = Start.
- [ ] DualSense over **Bluetooth**: all face buttons, D-pad, both sticks, L1/L2/R1/R2, Start/Select react.
- [ ] DualSense over **USB**: same.
- [ ] Overlay appears on mouse move, hides after ~2.5 s. FULLSCREEN fills the screen (Chrome and Safari); Esc exits.
- [ ] CONTROLS overlay lists 24 rows and the keys match what the emulator actually uses after remapping in the emulator menu → Control Settings.
- [ ] In a game that writes a memory card: save in game, reload the page, start the game → save is still there.
- [ ] Emulator menu → Export save downloads `<title>.srm`; Import save loads it back.
- [ ] ← LIBRARY performs a full page load back to `/` (address bar flashes, emulator gone).
- [ ] DevTools → Network while adding and playing a local game: no request contains the file name or bytes (only `cdn.emulatorjs.org` and the app's own assets).
- [ ] Theme toggle DARK/GREY in header: switches instantly, survives reload, no flash of the wrong theme.
- [ ] Settings → add a BIOS `.bin` you own → name shown; start a game → the "No BIOS found" warning no longer appears in the console. Remove BIOS → warning returns.
- [ ] Settings → Clear local data asks twice, then "My games" is empty and storage meter drops.
- [ ] Drop a lone `.bin` → red notice naming the `.cue`. Drop `.bin` + `.cue` together → one tile.
- [ ] Drop two `.chd` discs of one title without `.m3u` → one tile; game boots from disc 1.
- [ ] Drop a file > 700 MB → blue "large image" notice, tile still added.
- [ ] Firefox and Edge: repeat drop → play → reload once each.

## Phone / tablet

- [ ] iOS Safari: "Choose files" button opens the picker; game runs; EmulatorJS touch gamepad appears; sound after first tap.
- [ ] Android Chrome: same.
- [ ] Library grid shows 2 tiles per row on a phone, 3 on a tablet; nothing overflows horizontally.

## Known limits in M1

- Free games section is hidden (manifest arrives in M2).
- EmulatorJS is loaded from `cdn.emulatorjs.org` (self-hosted in M5).
- "Play anyway" after a storage-quota error works only via that link in the same visit.
