# Roadmap M2–M5 (task outline; each milestone gets its own full plan before it starts)

**Spec:** [design](../specs/2026-11-09-ps1-player-design.md) + [spec.md](../../../spec.md). Builds on the M1 plan's interfaces (`localDb`, `useEmulator`, `GameTile`, tokens).

## M2 — Free games (needs owner's approved titles, spec §10 Q5)

1. **Manifest + validation** — `content/free-games.json` (schema from spec §6.1; `file`/`cover` absolute URLs on `https://games.memcard.devffice.com/…`); `shared/freeGames.ts` with `parseManifest()` (zod) rejecting entries without `license`/`sourceUrl`; unit tests; ships empty.
2. **Public R2 bucket** `memcard-games-public` with custom domain `games.memcard.devffice.com`, CORS `GET, HEAD` from `https://memcard.devffice.com`, `ExposeHeaders: Content-Length`, long cache headers. `scripts/publish-free-game.mjs` (wrangler r2 put + manifest check).
3. **Home grid** — "Free games" section with `GameTile` (cover from manifest, author, licence line); hidden when manifest empty (test).
4. **Player `source=free`** — `EJS_gameUrl` = manifest URL (URL mode, EmulatorJS cache allowed), `EJS_gameName` = title; network-failure notice with retry; e2e on a clean context: one click → running.
5. Manual checklist M2.

## M3 — Owner login + private library (R2)

1. **Supabase project** — Auth with sign-up disabled, owner user created manually; `games` table + RLS per spec §6.3 (`storage_path` → `discs jsonb` of `{ key, name, size }`); `supabase/migrations/*.sql`; `@nuxtjs/supabase` (`redirect: false`); env `OWNER_USER_ID`, `SUPABASE_*`, `R2_*`.
2. **Owner guard** — `server/utils/requireOwner.ts` (session user id === `OWNER_USER_ID` else 404); `/login` page (email+password), not linked from UI; tests: anon → 404, non-owner user → 404.
3. **Storage interface** — `server/utils/storage.ts` (`createMultipart`, `signPart`, `completeMultipart`, `abortMultipart`, `getSignedUrl`, `delete`) with R2 implementation via `aws4fetch`; private bucket `memcard-games-private`, CORS `PUT, GET` from the app origin, `ExposeHeaders: ETag`.
4. **Upload** — routes `library/upload/{create,sign-part,complete,abort}`; client `useCloudUpload()` with 16 MiB parts, parallelism 3, progress, resume state in IndexedDB (`uploads` store), re-pick-file resume; single-file images only (`.chd`/`.pbp`), N discs per game.
5. **Library CRUD** — `library/list|rename|delete`, cover upload (private, presigned on list); "My library" section rendered only for owner (SSR via `serverSupabaseUser`); visitors get no markup at all (test).
6. **Play `source=cloud`** — `library/play-url` (presigned GET, 300 s) → app `fetch` with progress → `File` → `useEmulator.start`; on 403 re-request once; disc picker + `?disc=n`; per-device cache opt-in (`cloudCacheOptIn` setting → store in `localDb` with `source:'cloud'`).
7. **Policy tests** — Vitest against local Supabase (`supabase start`): RLS select/insert/update/delete as anon, as another user, as owner; API 404s; presigned URL expiry (clock-shifted signature) returns 403.
8. Deploy secrets (`wrangler secret put`), manual checklist M3 (file > 500 MB upload on Mac, play on phone and TV browser).

## M4 — Save sync for the owner

1. `saves` table + RLS; private bucket `memcard-saves-private`; routes `saves/get|put` (through the Worker, small files).
2. Client: `EJS_onSaveSave`/`EJS_onSaveUpdate` → debounce → PUT memcard (`kind: 'memcard'`); on game start for `source=cloud`, GET latest and inject before boot (method pinned in a spike: `EJS_loadStateURL` for states; memcard injection path per EmulatorJS internals, verified against 4.2.3 source).
3. Save states: `EJS_onSaveState`/`EJS_onLoadState` → slot files.
4. Last-write-wins by `updated_at`; conflict notice when local is newer.
5. Manual checklist M4 (two devices).

## M5 — Polish

1. **Self-host EmulatorJS** `public/emulatorjs/4.2.3/data/` trimmed to loader, emulator files, `cores/pcsx_rearmed*` and `cores/mednafen_psx_hw*`; `emulatorjsBase` → `/emulatorjs/4.2.3/data/`; verify each asset < 25 MiB; keep EmulatorJS LICENSE in that folder.
2. **Mobile layout** — 2/3-column grid, DropZone → button, overlay tap targets ≥ 44 px, safe-area insets on `/play`.
3. **Controls overlay** polish (live reading when mapping changed in EJS menu), optional `mednafen_psx_hw` core switch in settings (needs BIOS present).
4. **Storage UI** polish, low-memory warning (`navigator.deviceMemory < 4`).
5. **A11y + perf pass** — Lighthouse ≥ 90 on `/`, focus states in both themes, reduced motion on Boot blocks.
6. Manual checklist M5 (TV browser).
